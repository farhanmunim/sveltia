Only follow these steps if you have already made an installation media and know what you are doing!

1. Completely shutdown your ASUS ROG X13 laptop
2. Now insert the Installation Media USB / boot drive into your laptop whilst the power is off
3. Whilst holding down the `Esc` key, press the power button once but still hold down the `Esc` key until you see a boot menu
4. After a few seconds, you should see the options to boot into different storage media – simply locate the name of your Installation Media USB with the arrow keys and click enter

Now follow the installation steps 🙂
